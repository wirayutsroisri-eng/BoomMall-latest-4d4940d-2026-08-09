# Customer & Identity / ลูกค้าและบัญชีผู้ใช้

ครอบคลุม:
- สมัคร/เข้าสู่ระบบ
- User ID
- Profile
- Role/Permission
- Seller/Creator/Admin
- Block/Suspend/Delete account
- Device/session
- Consent/Privacy

## ข้อมูลสำคัญ
แยก PII ออกจากข้อมูลสาธารณะเท่าที่ทำได้ และกำหนดสิทธิ์เข้าถึง

## Account lifecycle
Created → Active → Restricted/Suspended → Deleted/Anonymized
